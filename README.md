# Program-Files-application-view-system-Demo
My idea of program files in linux. It creates a folder called program file with folders for each program you installed. And in each folder for that program, you get links to the actual files in the system.

How to try:
1. Download the appview.py file
2. Open a terminal in the download directory
3. First run a preview: python3 appview.py --dry-run
4. If the output look reasonable, generate the directories and links: python3 appview.py
